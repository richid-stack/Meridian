# compose

Write a post: insight, question or poll, with an optional company, book, deal or story attached.
Prototype source: `screens/compose` + p5 composer.
Rules: 500 characters, polls need 2 to 4 options, posts with a deal must not promise returns (`domain/community/draft.ts`, checked again by the API).
Not built yet: photo, video and voice attachments. They arrive with the uploads module.
