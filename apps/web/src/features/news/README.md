# news

Top stories and the story page. Prototype source: p7.
Data: `api.news.list(query)` and `api.news.get(id)`. Filters live in the URL (`?region=west&topic=fintech&page=2`), so every view can be shared.
Only headlines and summaries are shown. Full articles open at the source.
Not built yet: Saved stories. They need accounts so they follow the person across devices.
